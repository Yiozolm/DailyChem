# 用户指南（面向化学同学）

本指南面向**不熟悉编程**的化学同学，带你从安装到走完一整套日常工作流。
不需要懂代码，按步骤操作即可。

## 1. 安装（只做一次）

1. 安装 [uv](https://docs.astral.sh/uv/)（Python 环境管理工具，按其官网一行命令安装）。
2. 拿到本项目文件夹后，在项目根目录打开终端，运行：

   ```bash
   uv sync
   ```

   这会自动装好所有依赖（包含化学库 RDKit）。

## 2. 启动图形界面

- **Mac / Linux**：终端运行 `bash run.sh`
- **Windows**：双击 `run.bat`

浏览器会自动打开 DailyChem 页面（通常是 `http://localhost:8501`）。
左侧是 7 个工作流页面，按编号从上到下就是推荐的使用顺序。

## 3. 完整工作流（一个化合物从头到尾）

### ① Compound Setup（结构）
输入 compound ID 和 SMILES，或上传 ChemDraw 导出的 `.cdx` / `.mol` / `.sdf`。
点击 **解析结构**，右侧显示分子式、分子量和带原子编号的结构图。

> 编号后的结构图能帮你在做谱图归属时对照原子位置。

### ② NMR Formatter（核磁文本）
在 MestReNova 里 `View → Tables → Multiplets`，把表格整列复制，粘贴到页面文本框
（或上传导出的 TSV/CSV）。选好核种（1H/13C）、频率、溶剂，点 **格式化 NMR**，
得到论文规范的 NMR 文本，可一键复制 / 下载。生成的文本会自动带到第 ④ 步。

### ③ MS / IR / UV（其它谱）
三个 tab：
- **HRMS**：填 SMILES + 选 adduct（如 `[M+Na]+`），程序自动算理论 m/z；填实测值还能算 ppm 误差。
- **IR**：粘贴波数列表（如 `3050, 2920, 1715`）。
- **UV-vis**：粘贴 λmax（可带 ε）。

生成的文本同样会自动带到第 ④ 步。

### ④ Experiment Record（实验记录）
填反应物、试剂、溶剂、温度、时间、后处理、纯化、产率等。表征字段（HRMS/IR/UV/NMR）
会自动填入前面生成的文本。选语言（中/英），点 **生成 Markdown**，得到实验记录初稿。

> 可选：下方有 **✨ LLM 润色草稿** 按钮，把记录润色成论文 SI 风格（需配置 API key，
> 见 FAQ）。输出标记为 draft，**务必人工核对后再用**。

### ⑤ Project Export（归档）
把这个化合物的结构、谱图、记录整理成统一文件夹，并可下载为 zip。
默认不覆盖已有数据。

### ⑥ NMR Assignment（归属草稿）
输入结构 + 1H peak list，程序基于规则库给出每个峰的**候选归属**和风险提示。
- 结果是候选，不是定论；每行有 `candidate` / `needs_review` / `confirmed` 状态。
- 只有你人工核对结构和原始谱图后，才手动标 `confirmed`。

### ⑦ History Search（历史检索）
把做过的化合物存进本地数据库，以后可按**子结构**或**结构相似度**查"我以前做过类似的吗"。
- *入库*：从归档批量导入，或把当前化合物一键加入。
- *检索*：输入 SMILES/SMARTS，选子结构或相似度，看历史命中。

## 4. 重要原则

- 所有 assignment、LLM 生成内容都是 **草稿**，需人工确认，工具不会声称一定正确。
- 工具**只读**你的原始数据，生成的新文件放在单独位置，不会覆盖原始谱图 / 记录。
- 拿不准时，参考 [`faq.md`](faq.md)。
